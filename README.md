# pixeldesk

Source code of **[pixeldesk](https://pixeldeskth.com)**, a Thai movie review site that tells you
where each movie is streaming in Thailand: Netflix, HBO Max, Apple TV+, Viu and more.

- [รีวิวหนังทั้งหมด](https://pixeldeskth.com/movies)
- [หนังใหม่เดือนนี้ ดูที่ไหนดี](https://pixeldeskth.com/new)
- [แนะนำหนังแยกตามแพลตฟอร์ม](https://pixeldeskth.com/platforms)

Built with Next.js, Supabase and TMDB data. The app lives in [`pixeldesk-mockup/`](pixeldesk-mockup/).
